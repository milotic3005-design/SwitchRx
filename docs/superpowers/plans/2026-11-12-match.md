# Match (One Look Across the Tools) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give Switching Protocols, Clinical Calculators, Drug Reference and the Break Room the same page header, field, button, mode-switch and section-card styles.

**Architecture:** Five shared pieces in `components/ui/` hold every look, and their class strings live in `components/ui/styles.ts`. Each task moves one group of files onto them. A source-scan test grows file by file: adding a file to its in-scope list turns the test red until that file is migrated.

**Tech Stack:** Next.js 15 App Router, React 19, TypeScript strict, Tailwind 4, lucide-react, Vitest 4 (node, no DOM).

**Spec:** `docs/superpowers/specs/2026-11-12-match-design.md`

## Global Constraints

- **Presentation only.** No calculation, clinical text, unit, rounding, threshold, default value, state setter or condition changes.
  - Every switch keeps its values, setter and default.
  - Nothing in `data/` changes.
- **Out of scope:** the Copilot (`components/copilot/`), the launcher, the Mixing Guide body and all search boxes keep their own styles.
- **Theme:** remapped theme classes only. Amber and rose mean a clinical signal. Both themes must work.
- **Text:** no text below 13px. The guard test `lib/ui/text-floor.test.ts` must stay green, and its rules hold: never write a small size behind a variant, and never write a small size in a comment.
- **Lint:** errors already on `main` stay as they are, and none may be added. Compare per file with `git show main:<file> | npx eslint --stdin --stdin-filename <file>`.
- **Browser checks:**
  - Show the Browser pane before them (`mcp__ccd_view__show_pane`, pane `preview`).
  - Wait one second after a theme toggle before a screenshot.
- **Commits:** end every commit message with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- **Never** stop a process you did not start, and never push without the user's go-ahead.

## Review Focus

1. **Unit switch inside a field.** A long number in a field with an in-field cm|in or kg|lb switch must not run under the switch. Checked in Task 3.
2. **Switch behaviour.** Each converted switch must change the same state as before, including its default on first load (Vancomycin opens on Empiric, IVIG on PI, IDSA with no sex chosen). Checked in Tasks 3–6.
3. **Disabled switch.** A disabled switch (Biologic before dose and volume) must look disabled and keep its hint. Checked in Task 4.
4. **Light theme.** The dark field fill and the violet active option must stay readable on parchment. Checked in Task 7.
5. **Switching Protocols' tabs.** The sliding-pill animation is removed. The Setup / Suggestions switch must still move between the two views, and "Find switching protocols" must still jump to Suggestions. Checked in Task 6.

**Interfaces:**
- Produces:

```ts
// styles.ts
export const fieldClass: string;   // 'w-full rounded-lg border border-white/10 bg-black/30 px-3 py-2.5 text-base font-medium text-white placeholder-slate-500 transition-colors focus:outline-none focus:ring-2 focus:ring-violet-500/30 focus:border-violet-500/50'
export const labelClass: string;   // 'block text-[13px] font-bold text-slate-400 uppercase tracking-wider mb-1.5'
export const quietButtonClass: string; // 'inline-flex items-center gap-1.5 rounded-lg border border-white/10 bg-white/5 px-3 py-1.5 text-[13px] font-medium text-slate-300 transition-colors hover:bg-white/10 disabled:cursor-not-allowed disabled:opacity-40'
export const primaryButtonClass: string; // 'btn-premium inline-flex items-center justify-center gap-2 rounded-xl px-6 py-3 font-medium disabled:cursor-not-allowed disabled:opacity-50'

// PageHeader.tsx
export function PageHeader(props: { icon: LucideIcon; title: string; description: string }): JSX.Element;
// Button.tsx
export function Button(props: ButtonHTMLAttributes<HTMLButtonElement> & { variant: 'primary' | 'quiet' }): JSX.Element;
// Segmented.tsx
export function Segmented<T extends string>(props: {
  options: readonly { value: T; label: string }[]; value: T | ''; onChange: (v: T) => void;
  ariaLabel: string; size?: 'md' | 'sm'; disabled?: boolean; className?: string;
}): JSX.Element;
// SectionCard.tsx
export function SectionCard(props: { icon: LucideIcon; title: string; tone?: 'neutral' | 'violet'; children: ReactNode; className?: string }): JSX.Element;
```

Shape of each piece:
- **`PageHeader`:**
  - an `h1` (`text-3xl font-bold tracking-tight text-white flex items-center gap-3`) with a tile (`bg-violet-500/10 p-2.5 rounded-xl border border-violet-500/20`, icon `text-violet-400`, size 20, strokeWidth 2);
  - then a `p` (`text-[15px] text-slate-400 mt-2`);
  - the wrapper has `mb-8`.
- **`Segmented`:**
  - track: `flex rounded-lg border border-white/10 bg-black/30 p-0.5`, `role="group"`, `aria-label`;
  - options: buttons with `aria-pressed`, active `bg-violet-500/20 text-violet-300`, idle `text-slate-400 hover:text-white`;
  - `md` is `px-3 py-1.5 text-[13px] font-semibold`, `sm` is `px-2 py-0.5 text-[13px] font-semibold`;
  - disabled is `opacity-50 cursor-not-allowed`;
  - `value` may be `''` (nothing chosen yet), in which case no option is pressed.
- **`SectionCard`:**
  - neutral `bg-white/5 rounded-2xl p-5 border border-white/10`, violet `bg-violet-500/10 rounded-2xl p-5 border border-violet-500/20`;
  - a header row `flex items-center gap-2 mb-3` with the icon (`w-3.5 h-3.5 text-violet-400`) and the title in `labelClass` minus `mb-1.5`.

- [ ] **Step 1: Write `lib/ui/match.test.ts`.** It reads files from disk like `text-floor.test.ts`. `IN_SCOPE` starts empty; tasks 2–6 add files to it.
