# Read (13px Text Floor and Main Answers) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Render no text below 13px anywhere in the app and give every calculator's main answer one shared, prominent style.

**Architecture:** One "Readability floor" block in `app/globals.css` raises every small text class to 13px, guarded by a node test that scans the source. A `MainAnswer` component and four `.answer-*` CSS classes carry the main-answer style; each calculator adopts them. A fix-up pass then repairs what the larger text cramps, tool by tool.

**Tech Stack:** Next.js 15 App Router, React 19, TypeScript strict, Tailwind 4, Vitest 4 (node environment, `**/*.test.ts`, no DOM).

**Spec:** `docs/superpowers/specs/2026-11-11-read-design.md`

## Global Constraints

- Change nothing in `data/` and no calculation function. This stage changes markup classes and CSS only.
- No visible text below 13px. The only exemption is the Solitaire card faces (`components/BreakRoom.tsx`, sizes built from `CW`).
- A fix-up never exempts text from the floor. It changes that tool's layout classes.
- Amber and rose mean a clinical signal. A main answer is neutral unless its colour carries a signal the calculator already computes.
- Every screen works in dark and light themes. After a theme toggle wait one second before a screenshot: the background fades over 0.4 s.
- Browser checks need the Browser pane shown (`mcp__ccd_view__show_pane`, pane `preview`); hidden, key presses and screenshots time out.
- Lint errors already on `main`, add none: `app/page.tsx` (1), `components/ClinicalCalculators.tsx` (2), `components/DrugReference.tsx` (14), `components/WaitGame.tsx` (2).
- End every commit message with `Co-Authored-By: Claude Fable 5.2 <noreply@anthropic.com>`.
- Never stop a process you did not start. Never push without the user's go-ahead.

## Review Focus

1. Text in a fixed-height or `leading-none` box (badges, pills, table cells with a set height): at 13px it must not clip. Checked in Tasks 1 and 5.
2. Light theme: a coloured main answer on the cream background must reach 4.5:1 contrast. Checked in Task 2.
3. A long main answer ("1,250 mg IV q12h", the HBV status sentence) at 28px or 20px: it wraps inside its panel at 1280px and does not overflow. Checked in Task 3.
4. Tables at 1280px (CADD's five columns, the IVIG and Biologic schedules) with 18px key numbers: no sideways scroll, no header on two lines. Checked in Tasks 4 and 5.
5. The Copilot at 13px: citation chips, source cards, the step timeline and history rows stay inside their columns. Checked in Task 5.

// Reads every .tsx file under app/ and components/ and app/globals.css from disk (node:fs).
const FLOOR = 13;
const selector = (cls: string) => `html .${cls.replace(/([\[\].:])/g, '\\$1')}`;

it('covers every text-size class below 13px in the floor block', () => {
  // classes: every match of /(?:[\w-]+:)*text-(?:xs|\[\d+(?:\.\d+)?px\])/g whose size is below FLOOR (text-xs is 12px)
  expect(classes.size).toBeGreaterThan(0);
  for (const cls of classes) expect(floorBlock, cls).toContain(selector(cls));
});

it('sets every small class in the block to 13px', () => {
  expect(floorBlock).toMatch(/font-size:\s*13px/);
  expect(floorBlock).not.toMatch(/font-size:\s*(?:[0-9]|1[0-2])(?:\.\d+)?px/);
});

it('has no numeric inline font size below 13', () => {
  // every match of /fontSize:\s*(\d+(?:\.\d+)?)/ in the .tsx files
  for (const { file, size } of inlineSizes) expect(size, file).toBeGreaterThanOrEqual(FLOOR);
});

it('builds a font size from a formula only on the Solitaire cards', () => {
  // files with /fontSize:\s*`/ (a template string)
  expect(filesWithComputedSizes).toEqual(['components/BreakRoom.tsx']);
});

it('keeps the eyebrow and nav-link helpers at the floor', () => {
  for (const name of ['.cc-eyebrow', '.cc-navlink'])
    expect(ruleBody(css, name), name).toMatch(/font-size:\s*13px/); // the rule that sets font-size
});
